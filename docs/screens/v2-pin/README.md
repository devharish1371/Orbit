# Shared chat pin — browser verification

All messages/accounts are disposable synthetic preview fixtures. Pinning, reload persistence,
opening the original, unpin and reload were verified. The test pin was removed afterward.
verification.json records six settled light/dark layouts at 320/360/412 CSS px, with a 44 px
pin target and no horizontal/control overflow. Initial transient viewport captures were
replaced with settled captures, rather than claiming the requested size from the API alone.

Pin lifetime/expiry/unsend/ownership and stale-unpin protection are verified by hosted tests.
No real partner contact. APK handovers and physical test batches are deferred at user request.
